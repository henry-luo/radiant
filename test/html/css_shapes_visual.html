Text around CSS shapes

Compare each text contour. The colored floats keep their dimensions; the wrapping boundary changes. Examples use an 8px shape margin unless noted.

1. Rectangular wrapping

shape-outside: none
The circle is painted inside a rectangular float. Every line beside it begins at the same edge. Compare this with the next example: the visible circle is the same size, while the shape used for wrapping follows its curved boundary. More words continue below the float when the paragraph is long enough.

2. Circle

shape-outside: circle(50%) border-box
The text follows the circular boundary. Lines near the top and bottom move closer to the center, while lines across the middle leave more room for the circle. The shape margin adds a small gap between the contour and the text. More words continue below the float when the paragraph is long enough.

3. Ellipse

shape-outside: ellipse(50% 50%) border-box
An ellipse has different horizontal and vertical radii. The available line width follows that oval over the full height of each line. Look for the gradual change in the left edge of this paragraph. The text returns to the full column width once the float and its margin have ended.

4. Polygon

shape-outside: polygon(0 0, 100% 50%, 0 100%) border-box
This triangular contour points into the paragraph. Lines become shorter toward the middle and become longer again below the point. Its painted outline uses the same polygon coordinates, so the relationship between the shape and the text is easy to inspect. The final lines use the full width.

5. Rounded inset

shape-outside: inset(8px round 24px) border-box
The inset moves the contour inward from the float's border box, and rounding softens its corners. The text follows that smaller rounded rectangle. The painted shape uses the same inset and radius. Observe the first line near the rounded corner and the later lines along the straight edge.

6. Larger shape margin

shape-outside: circle(50%) border-box; shape-margin: 24px
The circle is the same size as example two, with a larger shape margin. The paragraph should keep a wider curved gap around it. Ordinary margins provide room for that expansion because a shape contour is clipped to the float's margin box. The text continues below the expanded contour.

7. Image alpha: low threshold

shape-outside: url(...); shape-image-threshold: 0.2
The image contains three bands with decreasing opacity, followed by a transparent band. At this low threshold, all three visible bands contribute to the wrapping boundary. The text leaves room for most of the image. Compare its starting edge with the higher threshold in the next example.

8. Image alpha: high threshold

shape-outside: url(...); shape-image-threshold: 0.8
Only the opaque band exceeds this threshold. The text can move into the space occupied by the faint bands, which remain visible underneath it. The image itself has the same size and pixels as example seven. This demonstrates how the threshold changes wrapping without changing the painted image.
